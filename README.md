# SpotBox - Spotify to Rekordbox playlist managaer
**SpotBox** bridges the gap between your Spotify library and your DJ sets.
Easily download your favorite tracks and playlists using spotDL, then sync them in Rekordbox using pyrekordbox. Use them directly in Rekordbox as if they were part of your Spotify collection.

🎧 *Harness the power of your Spotify playlists in Rekordbox.*

This tool helps DJs streamline their workflow by using Spotify as a reference and organization tool, while keeping everything Rekordbox-ready and performance-compatible.
